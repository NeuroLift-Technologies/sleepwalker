# Intent Logs

Store intent logs here when an agent plans a broad-scope, architectural, or
irreversible action.

- Use `templates/intent-log.md`.
- Name files `[date]-[topic].md`, for example `2026-06-03-docs-inventory.md`.
- Fill in the `Outcome` section after the action is complete.

Routine, narrowly scoped edits do not require an intent log unless the active
thread or reviewer asks for one.
